# 修改密码契约及安全边界

`POST /api/auth/password` 仅限管理会话，必须同源 Origin 和 X-CSRF-Token；API key 不可用。
输入严格为 `{currentPassword,newPassword,confirmPassword}`：原密码1–200字符，新密码12–200字符，确认一致且与原密码不同，不裁剪密码空格。返回 `{data:{ok:true}}` 并清空会话 Cookie。错误400输入、403原密码或CSRF、401会话过期、409并发修改、429限流；不自动重试。

新建单行 admin_credentials（密码盐及PBKDF2摘要、版本、时间、操作标记），无记录时兼容环境初始摘要。sessions 新增 credential_version 默认0，现有会话兼容。登录按验证时的凭据版本条件插入；改密以版本及原摘要CAS写入、事务删除所有管理会话并记录脱敏审计。session读取校验当前凭据版本，阻止旧密码登录与改密竞争产生有效会话。

前端消费者为独立 Password.vue 和顶部账号菜单；不进入公开设置/内容API/OpenAPI。所有字段只存在表单内存，离开销毁，不写浏览器存储；成功清空后重新登录。请求体/密码/摘要禁止进入日志、审计或响应。

风险验收：原密码错误、确认不符、短/超长密码、跨站/缺CSRF、无会话、API key、旧密码及旧会话失效、初始环境兼容、并发CAS、事务回滚、限流。测试使用独立Miniflare D1，不修改实际管理员密码。新增表为1行、低频人工修改；迁移仅加表和列。备份本地后执行迁移；回退代码须保留凭据版本校验，不可回退到仅环境摘要的登录实现。
