# OrbitPress v0.1.0 — 发布说明草稿 / Release draft

**状态：未发布。此文件不是 GitHub Release。**

首版提供基于 Astro/Vue/Cloudflare 的博客、文章与页面管理、Markdown 编辑及预览、可视化装修、公开博客导入、本地化图片、内容 API、中英文界面及文档。新增可选 Google AdSense 设置，默认没有发布商 ID、不请求广告。

## 安装与升级

按 [README](../../README.md) 安装。新安装的文章、页面、分类和自定义导航为空，保留首页；请修改初始化账号密码。新增广告设置读取时自动补默认值，复用现有设置表，无新增广告表或必需的数据迁移。

已有站点先备份 D1/R2 与生产 Secrets，再按原有部署流程升级。不要重新生成已有 API 密钥使用的加密配置。隐私说明可在后台补充，AdSense 申请、CMP 配置和广告审核由站长完成。

## 发布前需核实

- 待发布 commit、日期、`npm run check` / `npm test` / `npm run build` / `npm run test:ads` 的实际结果。
- 云端部署与 GitHub Actions 的实际状态；本地测试不代表这两项完成。
- 第三方商业组件与素材的分发权限，见 [THIRD_PARTY_NOTICES](../../THIRD_PARTY_NOTICES.md)。

## 限制与恢复

采集不保证兼容所有博客主题；视频受来源平台的嵌入与地区限制。AdSense 无真实账号时无法验证广告投放、审核或收入。内置隐私说明需要按站点实际情况完善。

关闭广告可以立即停止后续页面加载广告脚本。回滚旧版本前，移除新增广告装修组件，避免旧布局 schema 拒绝读取。数据库和媒体不随代码版本自动回滚。

The initial release includes Astro/Vue/Cloudflare blogging, post/page management, Markdown editing and preview, visual layouts, public blog imports, locally hosted images, content APIs and Chinese/English UI and documentation. Optional Google AdSense settings are disabled and empty by default.

Follow the [English README](../../README.en.md). New sites contain no personal content or custom categories. Change the initial administrator password. Advertising uses the existing settings table with safe defaults and requires no additional database migration. Back up existing data and preserve production Secrets when upgrading.

Before publishing, record the actual target commit, date, checks, tests, build, advertising integration results and CI/deployment status. Verify commercial component and asset redistribution rights. No live AdSense serving or approval has been verified without an account. Complete the privacy information and Google CMP settings for the actual site.

Disable advertising to stop loading its script on subsequent views. Remove new advertising layout widgets before rolling back to code with the older schema. A code rollback does not restore database or media snapshots.
